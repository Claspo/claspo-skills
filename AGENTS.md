# AGENTS.md

Rules for writing and editing the skills in this repository.

- **This repository is public.** Write only what helps someone outside the company: no internal repository names or paths, service topology, staging URLs or team workflow. That material belongs in the private skills repository.
- **State rules as facts, in prose that stands on its own.** Don't teach a rule by citing a commit hash or pointing at an example file: pointers rot, and a skill has to work for someone who reads only the skill.
- **Keep each skill to its own domain.** Where a topic belongs to another skill, point to that skill instead of copying its details, above all volatile values such as enum or wire strings, which go stale in the copy first.
